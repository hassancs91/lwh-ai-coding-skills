# Usable for everyone

### Accessibility
- What: Usable by everyone.
- Applies when: the app has screens.
- Stage: day-one-if
- Kind: checkable
- Done when: Every page works by keyboard alone, form fields have labels, and an automated accessibility scan reports no serious problems.

### Responsive design
- What: Works on every screen.
- Applies when: the app is used on different screen sizes.
- Stage: day-one-if
- Kind: checkable
- Done when: Every screen is usable at phone width: nothing cut off, no sideways scrolling, buttons large enough to tap.

### Screen states
- What: Loading, empty, error, done.
- Applies when: the app has screens that load data.
- Stage: day-one-if
- Kind: checkable
- Done when: Every screen that loads data shows a loading state, an empty state and an error state. Tests force each one.

### Localization
- What: Ready for other languages.
- Applies when: the app must work in more than one language.
- Stage: day-one-if
- Kind: checkable
- Done when: All visible text comes from translation files. Switching language changes every screen, including right-to-left layout where the language needs it.
