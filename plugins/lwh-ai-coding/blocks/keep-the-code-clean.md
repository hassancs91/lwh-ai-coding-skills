# Keep the code clean

### Modularity
- What: Small files that each do one job.
- Applies when: every app.
- Stage: day-one
- Kind: checkable
- Done when: Each file has one job that can be said in one line, and no file has become a catch-all.

### Separation
- What: Separation of concerns: keep screens, rules and data apart.
- Applies when: every app.
- Stage: day-one
- Kind: checkable
- Done when: Screen code, business rules and data access live in separate places, and the rules can be tested without the screen.
